Что намеренно не сохраняется

Bibika не сохраняет пароли, Authorization-заголовки, cookies, содержимое запросов и query-параметры URL. Похожие на токены длинные сегменты пути автоматически заменяются на [redacted].

Публичный монитор также не ведёт журнал обычных посетителей. Collector получает только Cloudflare Security Events и намеренно не запрашивает query string или содержимое запросов. В D1 сохраняются только данные, нужные для расследования: время, действие Cloudflare, источник защиты, IP, страна, ASN, hostname, безопасно обработанный путь, описание правила и User-Agent.
